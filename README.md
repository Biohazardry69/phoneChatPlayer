# phoneChatPlayer
A simple (and most likely shitty) player to fake phone chat messages.

Try it out here:
# https://biohazardry69.github.io/phoneChatPlayer/

You can take a look at the [example JSON](https://github.com/Biohazardry69/phoneChatPlayer/blob/main/chat_demo.json) file to see all options.

Warning: The entire thing was vibe-coded. It seems to work, and I skimmed over the code to make sure there was no big BS in there, but it might act weirdly

## Q & A

***Why did you do that?***

Because I always wanted to use this as a storytelling element. You can't really capture the dynamic typing, pausing, and deleting of text parts in static images.

***Why does the "send" event not automatically send whatever is in the textbox?***

Because I don't always want the typed text to match the sent text, imagine someone typing a sentence, but the message that appears is just "Moo Moo".
